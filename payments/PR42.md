# PR #42 — Test-mode payment backend (NOT deployed)

This branch stages Firebase Functions v2 endpoints and a Paystack **test-only** adapter. No payment button is enabled. Existing WhatsApp checkout is unchanged.

## Endpoints (admin-only except signed webhook)
- `initializeTimzyTestPayment`: Firebase ID token for fixed owner UID, product IDs and quantities, email. Reads Firestore catalog, computes server total, creates a pending test order and initializes Paystack checkout.
- `verifyTimzyTestPayment`: owner-only reference lookup and server-side verification.
- `timzyTestWebhook`: signature validation over raw bytes, provider verification, idempotent Firestore transaction to `paid_test`.

All endpoints return 503 unless `PAYMENTS_TEST_ENABLED=true`. The Paystack secret must be a **test** key, provided through Firebase Secret Manager as `PAYSTACK_TEST_SECRET`. Configure `PAYSTACK_TEST_WEBHOOK_SECRET` separately. Never commit secrets. The function code has not been deployed or connected to the website.

## Safety limitations / release blockers
- **Admin test harness only**. Customers cannot initialize payments; customer auth, anti-abuse, and safe checkout UX are not implemented.
- **Variants and stock:** implementation rejects products with explicit variant/stock fields and line items with variant choices. Catalog structure must be audited before supporting materials or reserving inventory.
- **Delivery/tailoring pricing:** shipping, measurement and customization charges are not included. Never use test totals as final customer invoices.
- **No order fulfillment or inventory changes** occur on test success. `paid_test` must never be treated as real revenue.
- **Do not deploy yet:** review security rules for `paymentTestOrders` (default deny client access), deploy configuration, billing eligibility, secrets, callback/webhook URLs, observability, emulator integration tests, rate limits and provider sandbox.
- Firebase function source requires `firebase-functions` and `firebase-admin`; install in `functions/`. Root `firebase.json` intentionally does not register Functions deployment yet.
- CI tests cover adapter contracts with mocked responses, not live Firebase or Paystack.
- Run `node --test payments/*.test.cjs` locally. No credentials needed.

Paystack docs: https://paystack.com/docs/api/transaction/ and https://paystack.com/docs/payments/webhooks/
